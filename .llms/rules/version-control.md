# Version Control

This repository uses **git** and **GitHub**, NOT Sapling (`sl`) or Mercurial (`hg`).

- Source control commands: use `git` (e.g., `git status`, `git add`, `git commit`, `git log`)
- Remote: GitHub (github.com/codimango org)
- Never use `sl`, `hg`, `jf`, or other Meta-internal VCS tools here
- This is a public benchmark task repo, not fbsource
